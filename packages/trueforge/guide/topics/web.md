covers: web
---

Ask Aman for the latest news or anything that changes often, and it searches the live web for you. It can give you the five stories that matter, with two lines each.

Web search needs a search provider. Open Settings and pick a web search provider. Without one, Aman says it cannot search the web.

When Aman searches, the search words and the pages it opens are sent to the search service.
