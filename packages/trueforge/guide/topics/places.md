Ask Aman to find a place, such as a quiet coffee shop near you, and to plan the walk there.

Aman uses a map service to look up places and routes. It sends the place names and routes to that service. Maps run without asking unless you turn off the **Maps** switch in Settings. With the switch off, each map shows a card first. The card also offers **Always allow in this chat** and **Always allow everywhere**. The first stops the question for that chat. The second turns the **Maps** switch back on. With the switch off, a scheduled run, such as a daily briefing, skips its maps. Each place shows only the details its web page states, with a link to the page. A detail the page does not give is left out, not guessed.

To find places, pick a web search provider in Settings first. See "Searching the web".
