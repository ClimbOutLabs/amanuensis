# Licenses read by hand for dependencies whose license metadata is missing or
# unclear. Used by scripts/check-dependency-licenses.mjs.
#
# One entry per line: `ecosystem:name@version :: SPDX expression :: where it was checked`
# (ecosystem is npm, pypi or go; PyPI names are lower case with dashes). The
# expression replaces the package's own metadata and must still pass the
# accepted list, so an entry can never let a copyleft or unlicensed package
# through. An entry that matches no dependency fails the check.
